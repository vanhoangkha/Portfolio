## Tech Stack

- **Frontend**: React 18 + TypeScript
- **Styling**: CSS Modules
- **State Management**: Zustand
- **Build Tool**: Vite
- **Testing**: Vitest + React Testing Library
- **CI/CD**: GitLab CI/CD
- **Deployment**: Kubernetes + Docker
- **Hosting**: AWS Amplify / GitLab Pages
